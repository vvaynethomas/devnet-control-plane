# DNCP Roadmap

## v0.1.0 — Foundational Nervous System (Current)
- Standalone zero-dependency Python package (`devnet-control-plane`).
- 6-Pillar Web Workbench on port 8780.
- Portfolio scanning across 22 repositories in `GitHub-Repos`.
- Cross-repo backlog aggregation with PAT-0001 router.
- SQLite FTS5 search across Factory entities & conversation transcripts.
- Multi-harness chat sync (Antigravity, VS Code Copilot, Microsoft Copilot import) and tokenomics.
- Composable InteractionFrame compiler & evaluation runner.

## v0.2.0 — Live Sync & Local Inference
- Background filesystem watcher for zero-click chat harvesting.
- Local LLM inference bridge for Interaction Lab benchmarks.
- Bi-directional sync with the ALM (Agent Lifecycle Management) agent registry.
